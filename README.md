# SQL Data Engineering Projects

This repository contains SQL projects I have worked on to improve my SQL skills and get more hands-on practice with data engineering tools.

The projects focus on working with real-world data, writing SQL queries, and finding useful insights from the data.

> Click on the project below to explore my analysis and see how I built it.

## Projects

### 📊 [1. EDA](/1_EDA/) - Data Engineer Job Market Analysis

![Project 1 Overview](/Images/1_1Project1_EDA.png)

In this project, I used SQL to analyze the data engineer job market. I focused on finding the most in-demand skills, the highest-paying skills, and the skills that provide the best combination of salary and demand.

I used DuckDB and MotherDuck to work with the job posting data and perform the analysis.
